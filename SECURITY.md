# Security policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

Earlier versions were never released.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub private vulnerability reporting:

1. Open the [Security tab](https://github.com/tattali/PresignedUrl/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, the affected version and, if you can, the steps to reproduce it.

The report is visible only to you and the maintainer. Please do not open a public issue or pull request for a vulnerability.

The [Security model](README.md#security-model) section of the README describes what the library protects and what it does not.
